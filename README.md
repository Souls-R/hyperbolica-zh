# Hyperbolica 简体中文汉化

非官方文本汉化，包含菜单、对白、选择项和提示。贴图中的英文保留。

**适用：Windows Steam 版 1.1.9（Build 8675290）。**

**[下载 v0.1.0-beta 汉化 ZIP](https://github.com/Souls-R/hyperbolica-zh/releases/download/v0.1.0-beta/Hyperbolica-zh-CN-v0.1.0-beta-steam-8675290.zip)**

## 安装

1. 关闭游戏，解压汉化包。
2. 将 `Hyperbolica_Data` 文件夹复制到 `Hyperbolica.exe` 所在目录，替换全部同名文件。
3. 从 Steam 正常启动游戏。

## 恢复英文

Steam 库 → 右键 Hyperbolica → 属性 → 已安装文件 → **验证游戏文件完整性**。

游戏更新或验证文件可能清除汉化；修改相同资源的其他 Mod 会互相覆盖。
